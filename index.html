CareerForge

Career preparation, connected in one workflow.

Career preparation often spans disconnected tools. CareerForge connects resume skill review, role-based learning plans, mock interviews, and job-description comparison in one account-backed workspace.

  • Review skills extracted from a resume
  • Follow a role-based learning roadmap
  • Save and resume interview practice
ReactSpring BootMySQL
Architecture & implementation +

A React interface communicates with a Spring Boot REST API. MySQL persists account data and learning progress; JWT authentication protects account access. Saved interview sessions support leaving and resuming practice.

Job matching uses keyword comparisons. Optional AI guidance requires server-side credentials. Further development and user testing are ongoing.

Leaf Bookstore

A complete storefront and administration workflow.

An online bookstore connecting product discovery and cart management with order handling and an admin panel. The application brings customer and store-management workflows together.

  • Browse books and manage a shopping cart
  • Manage products, inventory, and orders
  • Try checkout with a simulated payment flow
ReactSpring BootH2Razorpay
Architecture & implementation +

React powers the storefront and admin interface. A Java Spring Boot backend manages products, accounts, orders, and inventory, with H2 persistence and Spring Security session authentication. Payment verification code integrates with Razorpay test mode.

Razorpay test-mode code is integrated; gateway testing awaits API keys. Simulated checkout is available.
