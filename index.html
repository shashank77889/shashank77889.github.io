Leaf Bookstore

A small store. A full shopping journey.

An online bookstore with a customer storefront and an admin panel. Built to explore how products, user accounts, orders, and inventory work together.

  • Browse books and manage a shopping cart
  • Manage products, inventory, and orders
  • Try checkout with a simulated payment flow
ReactSpring BootH2Razorpay
What this project taught me +

How a shopping flow connects the interface, backend, database, and payment verification—and why a simulated checkout is useful while setting up a gateway.

Razorpay test-mode code is integrated; gateway testing awaits API keys. Simulated checkout is available.
